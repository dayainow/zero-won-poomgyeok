Chapter 03 — Screen Specifications

12개 화면 풀 명세.

각 화면마다 풀 사이즈 목업 + 번호 콜아웃 + 컴포넌트 스펙 + 인터랙션 + 상태(로딩/빈/에러)를 명시한다. 개발자가 이 문서만 보고 구현 가능하도록.

① ~ ⑦ Component Annotations

1
Brand Wordmark — "0"만 colors.accent, 나머지 colors.text. 토큰: typography.display.
2
Header Actions — 검색 + 알림 종 (24px, stroke 1.6). 종 탭 → NotificationsScreen.
3
CategoryRow — 6개 카테고리 (전체 / 전시 / 공연 / 클래스 / 행사 / 공간). 가로 스크롤. 활성: 아이콘 배경 라임. 비활성: bg-raised.
4
FeaturedCard — 16:10 이미지, 좌상단 무료 뱃지, 우상단 X(관심없음), 하단 그라데이션 위 제목+위치, 우하단 좋아요 카운트.
5
StatsRow — 3개 카드 (오늘 무료 / 만원 이하 / 주말 추천). 첫 카드만 highlight variant (라임 배경). 숫자는 numberLarge 30/800.
6
NearbyGrid — 3열 정사각 카드. 좌상단 무료 뱃지, 하단 그라데이션 위 제목+거리. 카드 탭 → DetailScreen.
7
BottomTabBar — 5탭 (피드 활성 = 라임). 가운데 +FAB (라임 원형, 8px above tabbar). FAB 탭 → ActionSheet.

4
RatingRow — ★ 별점 (accent) + 리뷰 카운트. 구분 pipe는 text-4.

7
MapPreview — 주소 행 + 100px 지도 + "길찾기" 버튼. 핀은 accent 색 22px 원형.
