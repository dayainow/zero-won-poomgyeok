01 — Value Proposition

네 가지 약속으로
문화의 문턱을 낮춥니다.

"거지문화생활"이라는 자조적 표현이 SNS 트렌드가 된 시대. 우리는 이를 자기비하가 아닌 자부심으로 바꾼다. 0원으로도 충분히 품격 있는 문화생활이 가능하다는 것을 증명하는 네 가지 약속.

VALUE 01
₩0
무료
0원으로 즐기는 문화생활. 입장료가 없는 전시·공연·공간을 모두 모았습니다.
VALUE 02
⌕
발견
취향을 찾는 새로운 시선. 알고리즘이 아닌 큐레이터가 고른 깊이 있는 추천.
VALUE 03
♡
저장
나만의 리스트로 정리. 가고 싶은 곳을 모으고, 다녀온 곳을 아카이브합니다.
VALUE 04
◉
가까이
지금, 내 주변에서. 위치 기반으로 즉시 갈 수 있는 곳을 우선 노출합니다.
02 — Problem & Opportunity

문화는 비싸지 않다.
정보가 비쌌을 뿐.

대한민국에는 매년 수천 건의 무료·저렴한 문화 행사가 열린다. 하지만 흩어진 정보, 단조로운 큐레이션, 발견 비용의 부담이 사용자를 가로막는다.

73%
"문화생활은 비싸다"고 응답한 20대 비율
SOURCE · 문화체육관광부 2024 국민여가활동조사
2,400+
전국 연간 무료 전시·공연 (집계 기준)
SOURCE · 문화포털 2024 통계
⊕
정보가 흩어져 있다
기관별 홈페이지, SNS, 블로그에 분산. 한 곳에 모인 큐레이션 서비스가 부재.
⊗
예산 필터가 없다
기존 서비스는 전체 행사를 보여줄 뿐, "내 예산에 맞는 것"만 빠르게 찾기 어려움.
⊘
위치 기반 큐레이션 부재
"지금 내 주변에서 갈 수 있는 무료 행사"를 즉시 찾는 도구가 없음.
⊜
선착순·마감 정보 누락
무료 행사는 선착순이 많지만 잔여석 알림이 없어 놓치는 경우 빈번.

04 — User Journey Map

인지에서 재방문까지.

사용자가 앱을 처음 만나는 순간부터 충성 사용자가 되는 다섯 단계. 각 단계마다 감정과 핵심 액션, 우리의 개입 지점을 명시한다.

STAGE 01
👀
인지 (Awareness)
SNS · 친구 추천
"거지문화생활 큐레이션 앱"이라는 키워드로 인스타그램·X·블로그에서 인지. 친구 공유로 다운로드.
"오 이런 게 있었네?"
STAGE 02
🚪
진입 (Onboarding)
위치 권한 · 관심 선택
3단계 온보딩으로 위치·관심 카테고리·예산 범위 설정. 첫 화면에서 즉시 "오늘의 추천"을 만남.
"내 취향대로 보여줘서 좋네"
STAGE 03
🔖
발견·저장 (Discover)
필터 · 저장 · 알림
카테고리·가격·날짜로 필터링. 가고 싶은 곳을 저장하고 마감 임박 알림을 받음.
"진짜 무료가 이렇게 많구나"
STAGE 04
🎨
참여 (Experience)
길찾기 · 예약 · 방문
예약하기 버튼으로 외부 사이트 연결, 또는 지도 앱으로 길찾기 인앱 연동. 현장 도착 후 체크인.
"실제로 가보니 좋은 곳이었어"
STAGE 05
↻
재방문 (Retention)
후기 · 공유 · 재탐색
간단한 별점·후기 남기고, "0원으로 다녀온 인증"으로 SNS 자동 공유 카드 생성. 다음 행사 추천 받음.
"매주 토요일 아침에 한번씩 봐야지"
05 — Information Architecture

하나의 앱, 12개의 화면.

5개의 메인 탭과 7개의 서브 화면. 모든 화면이 명확한 진입 경로와 빠져나오는 길을 갖는다.

06 — User Flows

네 가지 시나리오.

실제 사용자가 앱을 사용하는 가장 핵심적인 4개 시나리오. 각 화면 간 이동과 분기점, 의사결정 지점이 명시됨.

FLOW 01
첫 진입 ~ 첫 발견
신규 사용자가 앱을 처음 켜고 5분 안에 첫 추천을 만남
FLOW 02
탐색 ~ 예약
행사 발견부터 외부 예약 완료까지의 핵심 전환 흐름
FLOW 03
저장 ~ 일정 관리
관심 행사 저장 후 일정 추적 및 알림 받기
FLOW 04
정밀 검색 ~ 결과
필터를 활용한 조건 기반 검색 흐름

FLOW 02
탐색 → 예약
FLOW 03

FLOW 04

09 — Tech Stack

가볍고 빠르게.

한 명의 풀스택 개발자가 4주 안에 MVP를 출시할 수 있는 가장 짧은 경로.

FRONTEND
React Native + Expo
SDK 51+, TypeScript strict. iOS/Android 동시 배포.
NAVIGATION
React Navigation
Bottom Tabs + Native Stack. 5탭 + 중앙 FAB 커스텀.
STATE
Zustand + TanStack Query
로컬은 Zustand, 서버는 React Query 5분 staleTime.
STYLING
StyleSheet + Theme Tokens
디자인 토큰 기반 (colors, typography, space, radius).
MAP
react-native-maps
Google Maps Provider. 다크 스타일 customMapStyle.
BACKEND (V1)
Supabase or Firebase
Auth, Postgres/Firestore, Push Notifications.
10 — Roadmap

세 단계로 완성한다.

MVP에서 시작해 콘텐츠 큐레이션 플랫폼으로 확장. 각 단계마다 핵심 가치를 검증하며 다음으로 나아간다.

PHASE 01
MVP 출시
2026.05 – 2026.06 · 4주
  • 12개 핵심 화면 구현
  • 서울권 행사 1,000+ 시드 데이터
  • 위치 기반 탐색 + 저장 + 알림
  • iOS/Android TestFlight·내부 테스트
  • 베타 사용자 100명 모집
PHASE 02
큐레이션 강화
2026.07 – 2026.09 · 12주
  • 큐레이터 콘텐츠 (이야기/스토리)
  • SNS 공유 카드 자동 생성
  • 예약 외부 연동 (인터파크, 예스24)
  • 친구 팔로우 + 추천 피드
  • 전국 5대 도시 확장
PHASE 03
플랫폼화
2026.10 – 2027.Q1
  • 주최자 등록 포털 (자체 행사 등록)
  • 유료 행사 직접 결제
  • 광고 사업화 (스폰서드 큐레이션)
  • 일본·대만 진출 검토
  • 웹앱 동시 출시
