계정을 유지한 채 데이터 삭제 (앱에서 직접)

  1. 저장한 행사: 앱 → 하단 저장함 탭 → 행사 카드 에서 저장 해제(삭제).
  2. 최근 검색어: 검색 화면 → 최근 검색 → 지우기.
  3. 위치 정보: 기기 설정 → 앱 권한 → 0원의품격 → 위치 권한 거부 또는 허용 안 함.

계정을 유지한 채 데이터 삭제 (이메일 요청)

아래 항목은 앱에서 바로 삭제할 수 없거나 서버에 저장된 데이터입니다. 계정을 삭제하지 않고 일부만 삭제하려면 이메일로 요청해 주세요.

  1. privacy@olalab.kr 로 메일을 보냅니다.
  2. 제목에 「0원의품격 데이터 삭제 요청」을 적고, 가입 이메일(또는 카카오 로그인 계정)과 삭제할 항목을 적어 주세요.
  3. 본인 확인 후 영업일 기준 14일 이내 처리 결과를 회신합니다.

이메일로 요청 가능한 항목 예시:

  • 작성한 후기(평점·코멘트)
  • 프로필·관심 설정·알림 설정
  • 서버에 저장된 저장함·최근 검색 동기화 데이터

계정 전체 삭제(회원 탈퇴)

  1. privacy@olalab.kr 로 「0원의품격 회원 탈퇴 요청」 제목의 메일을 보냅니다.
  2. 가입 이메일을 기재합니다.
  3. 확인 후 계정 및 연동 데이터를 삭제합니다(법령상 보관 항목 제외).
